# 冰火交融 · 矿山街角驿站

一个用 Three.js 实时渲染的**三维微缩景观**（不是 Blender 工程，纯 WebGL）。
打开即是一整块可自由拖拽、旋转、缩放观看的收藏级模型，画面上没有任何 UI 元素。

---

## 怎么打开

**双击 `index.html` 就行**（Chrome / Edge 均可）。

> 需要联网：Three.js r160 通过 CDN（jsdelivr）加载，首次打开约 1~2 秒。
> 如果想完全离线，见文末「改成离线版」。

打开后：

- 鼠标左键拖拽 = 旋转
- 滚轮 = 缩放
- 右键拖拽 = 平移（有范围限制，不会把模型推出画面）
- 静置时会极慢自转，一旦操作就停下

## 怎么改

改 `src/` 里的任意文件，然后重新构建：

```bash
python build.py
```

`build.py` 会把 8 个 js 按文件名顺序拼进 `index.html` 的 `<script type="module">` 里。
**不要直接改 index.html**，下次构建会被覆盖。

### 常用调试参数（加在 URL 后面）

| 参数 | 作用 | 例子 |
|---|---|---|
| `?cam=x,y,z` | 指定相机位置 | `index.html?cam=-8,9,13` |
| `?tgt=x,y,z` | 指定看向的点 | `index.html?tgt=0,1,0` |
| `?t=5` | 冻结时间在第 5 秒（截静帧用） | `index.html?t=5` |

例：`index.html?cam=-3.4,3.4,6.4&tgt=-3.9,0.4,1.4&t=5`

### 常调的参数在哪

- **整体亮度 / 曝光**：`00-core.js` → `renderer.toneMappingExposure`（默认 1.14）
- **泛光强度**：`00-core.js` → `new UnrealBloomPass(..., 0.32, 0.52, 1.02)` 第 2、3、4 个参数分别是强度、半径、阈值
- **主光方向**：`00-core.js` → `keyLight.position.set(8.5, 13, 7.5)`
- **初始视角**：`00-core.js` → `camera.position.set(-8.3, 9.5, 13.6)` 与 `controls.target`
- **熔岩流动速度 / 颜色**：`10-base.js` → `lavaMaterial(speed, hot)`，以及 `cA/cB/cC` 三个色
- **水面颜色**：`10-base.js` → `waterMaterial()` 里的 `cDeep / cMid / cIce`
- **雨雪密度**：`50-fx.js` → `RAIN_N`、`SNOW_N`

## 几个必须知道的坑（改之前建议先看）

1. **不要出现共面**。两个面间隙为 0 就会闪（z-fighting）。
   贴图面、玻璃面与母体前面至少错开 **0.008**；玻璃盒子要放在实体**外侧**，不能和实体同面。
   （这个项目已经踩过三次：窗框 vs 墙洞、售货机玻璃 vs 展示窗、冰封柜玻璃 vs 柜体。）

2. **动态物体不能进静态描边合并**。
   描边是把所有静态网格的几何烘焙到世界坐标后合并成一个 BackSide 外扩壳。
   会动的物体（门扇、旋转龙晶、索道吊篮）必须 `userData.outline = false`，
   再单独用 `childOutline(mesh)` 挂一个子级描边，否则它的静止轮廓会留在原地。

3. **窗框内衬必须是环形**（Shape 带 hole）。实心板会把室内完全挡住。

4. **地面光斑要高于人行道**。人行道顶面 y=0.13，光斑平面放 0.148，否则被铺装盖住。

5. **材质变量名**：色板对象叫 `PAL`，圆柱助手叫 `C()`，别撞名。

6. **构建脚本里别用 Python 的 `%` 格式化**（CSS 里有大量 `%`），用的是 `__JS__` 占位符替换。

## 改成离线版（可选）

如果要在没网的环境跑：

1. 下载 `three@0.160.0` 的 `build/three.module.js` 和 `examples/jsm/` 下用到的模块
   （OrbitControls、EffectComposer、RenderPass、UnrealBloomPass、OutputPass、
   ShaderPass、MaskPass、Pass、CopyShader、LuminosityHighPassShader、OutputShader、BufferGeometryUtils）
2. 按相同目录结构放到 `vendor/` 下
3. 把 `index.html` 里的 importmap 改成：
   ```json
   { "imports": { "three": "./vendor/three.module.js", "three/addons/": "./vendor/jsm/" } }
   ```

注意：**本地模块在 `file://` 下会被浏览器拦截**，离线版必须起个本地服务：

```bash
python -m http.server 8000
# 浏览器打开 http://127.0.0.1:8000/index.html
```

## 性能

约 700~900 个网格 + 合并描边 + 泛光后期。桌面独显 / 集显基本 60fps。
内置自适应：连续掉帧会自动降渲染分辨率（最低 0.85x），不需要手动干预。

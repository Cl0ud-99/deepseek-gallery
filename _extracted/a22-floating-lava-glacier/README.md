# 浮空熔岩 · 冰川断崖微缩箱庭

一个用 Three.js 实时渲染的奇幻箱庭场景：方形底座上，浮空火山岛悬在冰川断崖之前，熔岩从火山口翻过岛缘直坠冰湖，冰层下还有一整套发光的水下世界。三渲二风格，可自由拖拽旋转缩放，没有任何界面元素。

---

## 直接看

双击 `index.html` 即可。**已经把所有依赖打包进去了，不需要联网、不需要起服务器**，断网也能跑。

- 左键拖拽：旋转
- 滚轮：缩放
- 静置 7 秒：自动缓慢旋转

---

## 改代码

`index.html` 是构建产物（约 580 KB，内含压缩后的 Three.js），**不要直接改它**。真正要改的是：

```
src/app.js               ← 全部场景代码（可读，约 76 KB）
src/index.template.html  ← 外层 HTML 壳（样式 / canvas 容器）
build.mjs                ← 打包脚本：esbuild 把 app.js 压成一个 module 内联进模板
```

改完执行：

```bash
npm install     # 首次需要联网装 three + esbuild
npm run build   # 生成新的 index.html
```

`npm run dev` 会构建后起一个本地服务器预览（可选，直接双击也能看）。

|---|---|
| 0–1 | 渲染器、相机、OrbitControls、噪声与随机数工具 |

| 5 | 天空、灯光（含熔岩暖光、冰下冷光） |
| 6–7 | 几何工具（`taperedTube` / `rockGeo` / `spikeGeo` / `terrainGeo`）与全局尺寸 `CFG` |
| 8–9 | 底座、冰川崖体、冰墙、冰冠 |
| 10–11 | 冰湖面、冰窟窿、冰下世界（熔岩柱 / 骨架 / 水母 / 金币 / 迷宫岩壁） |
| 12–13 | 浮空火山岛、岩浆河 + 火瀑（**一整条连续曲线**） |
| 14–17 | 冰笋、结晶树、锁链、云海、雪、底座边缘双色溪流 |
| 18–19 | 后处理（Bloom + 暗角调色）与动画循环 |

### 常改的几个数

- **相机**：`camera.position.set(...)` 与 `controls.target.set(...)`
- **底座尺寸**：`CFG` 里的 `lakeX0/X1`、`lakeZ0/Z1`、`iceY`、`floorY`
- **岩浆路径**：`lavaCurve`（岛局部坐标，14 个控制点，前段是河道、后段是瀑布）+ `lavaR(t)` 半径函数
- **出浆口岩石**：`// rock lip the lava pours over` 那一段的 `lip` / `lip2`
- **配色**：各处的 `0x......`，冰系偏青蓝、岩体偏紫、熔岩橙红

## 几个坑（改的时候注意）

1. **绕曲线生成的管体，不要用 `mesh.scale.x` 改截面。** 这类几何是以曲线为轴生成的，mesh 级缩放会以物体原点为中心把整根管子推走（会变成两根）。要改截面请改 `taperedTube` 的半径函数。
2. **需要视觉连续的流体，做成一个 mesh。** 两段管道在端点对接，从侧面能直接看进管腔，永远有一条暗缝。
3. **给流体加承托物时，岩石必须在落点后方。** 往前探一点就会把水流“切断”。
4. `MeshToonMaterial` 开 `vertexColors` 时，几何体必须带 `color` 属性，否则整片变黑。
5. 首帧会先 `renderer.compile()` 预热再淡入，避免预览时闪黑。

## 性能

约 950 个对象（含描边子网格），2048 阴影贴图，Bloom + 调色后处理。桌面独显/集显都能跑；移动端会自动拉远相机并放大 FOV。

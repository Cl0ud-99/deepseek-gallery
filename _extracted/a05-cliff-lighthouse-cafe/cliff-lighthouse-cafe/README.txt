Cliff Lighthouse Cafe · 海崖灯塔咖啡馆
=================================
完全自包含单文件版（Three.js 与场景代码已全部内联）。
无需联网、无需安装任何东西、无需本地服务器。

使用方法：
  直接双击 index.html，用 Chrome / Edge 打开即可离线运行。

操作：
  左键拖拽 = 旋转视角
  右键拖拽 = 平移
  滚轮     = 缩放

可选参数（加在地址栏 URL 后）：
  ?nopost=1              关闭后处理
  ?cam=x,y,z,tx,ty,tz    指定初始机位

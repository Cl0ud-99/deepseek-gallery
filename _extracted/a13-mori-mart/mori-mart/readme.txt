森のコンビニ — 萤火雨夜微缩场景
================================

【怎么打开】
  双击 index.html 即可（推荐 Chrome / Edge / Safari）。
  这是离线单文件版：three.js 已打包进 HTML，不需要联网、不需要安装任何东西、也不需要本地服务器。
  整个场景约 60 万字符，首次打开约 1~2 秒出现画面。

【操作】
  左键拖拽 …… 环绕旋转
  滚轮 / 双指 …… 缩放（拉近看店内细节）
  右键拖拽 …… 平移
  画面内没有任何按钮和文字，就是一个纯粹的微缩模型。

【关于 source 文件夹】
  里面是可读源码版本（未压缩），three.js 通过 CDN 加载，需要联网。
  想继续改场景、加道具、调动效，改这个文件更方便；
  改完若要重新打包成离线单文件，可用 esbuild 把 module 脚本打成 IIFE 后内联。

【提示】
  - 若打开是黑屏：请在浏览器设置里开启“硬件加速 / WebGL”。
  - 场景为程序化生成，无外部贴图与模型文件，整个包只有这一个 HTML。
  - 预览图 preview.png 是默认机位的样子。

# 夏夜游乐园 · 掌上八音盒

一个可以自由拖拽 / 旋转 / 缩放的微缩三维游乐园场景。纯 WebGL（Three.js）实时渲染，
没有用 Blender，也没有任何外部网络依赖——双击 HTML 就能看。

---

## 一、先看成品

打开 `carnival.html` 即可。

- 左键拖拽：旋转视角
- 滚轮 / 双指：缩放（12 ~ 74 之间）
- 右键拖拽：已禁用（保持构图不乱跑）
- 闲置 7 秒后镜头会自己慢慢转，一碰就停

> 单文件 743KB，引擎、后期、贴图全部内联。断网、拷到 U 盘、发给别人都能直接跑。

## 二、目录结构

```
carnival.html        ← 构建产物（自动生成，别直接改这个）
build.sh             ← 构建脚本：把 src + lib 拼成单文件
src/
  _head.html         ← HTML 外壳（样式、淡入遮罩）
  01_core.js         ← 渲染器 / 相机 / 灯光 / 材质工厂 / 贴图工厂 / 描边 / 灯泡类
  02_world.js        ← 夜空、星星、月亮、拼花底座、木栈道
  03_carousel.js     ← 双层旋转木马（木马、马车、天鹅、楼梯、华盖、飞马）
  04_booths.js       ← 售票亭、甜品摊、CARNIVAL 霓虹拱门
  05_props.js        ← 围栏、气球、爆米花车、棉花糖机、小丑机、哈哈镜、长椅、灯柱、垃圾桶、望远镜

```

## 三、怎么改

**改完一定要重新构建**，否则 `carnival.html` 不会变：

```bash
bash build.sh
```

Windows 上用 Git Bash 执行；脚本只做一件事——按顺序把 `lib/` 和 `src/` 的文件拼进 HTML 模板。

### 常改的几个地方

| 想改什么 | 去哪里找 |
|---|---|
| 默认视角 / 缩放范围 | `01_core.js` 里 `camera.position.set(...)`、`controls.minDistance/maxDistance` |
| 整体配色 | `01_core.js` 顶部 `const C = {...}` 调色板 |
| 灯光亮度 | `01_core.js` 的 `hemi / key / fill / rim` 和 `lights` 数组 |
| 地砖花纹 | `01_core.js` 的 `APP.tileTexture()`，四组颜色数组 |
| 木马旋转速度 | `03_carousel.js` 末尾 `spin.rotation.y += dt * 0.16` |
| 木马起伏幅度 | 同上，`Math.sin(t * 1.15 + h.phase) * 0.19` |
| 跑马灯节奏 | `01_core.js` 的 `Bulbs` 类里 `speed / spread / gain` |
| 烟花频率 | `06_anim.js` 里 `fwTimer = 2.6 + Math.random() * 3.4` |
| 泛光强度 | `06_anim.js` 里 `new THREE.UnrealBloomPass(..., 0.26, 0.42, 0.9)` 三个参数 |

## 四、几个必须知道的坑（踩过的）

1. **不要删 `finalPass`**。整个场景走的是「sRGB 输出 + 材质色转线性」的管线，
   最后靠这个 pass 做 gamma 和暗角。删掉画面会整体发暗、发灰。

2. **金属大面积平板会变暗褐色**。金属材质反射的是深色夜空，一整片金色板子会变成巧克力色。
   金饰请做成细边条、环、肋，不要做大平面。

3. **开场镜头别用「逐帧累加 dt」**。低帧率设备上会定格在远处。现在是真实时间轴 + `introDone` 标记。

4. **装饰别放在木马半径上**。花环、灯串如果和马同半径同高度，会长在马背上。

5. **性能**。全场景约 2800 个 mesh。桌面独显 60fps 无压力；核显或移动端如果卡，
   优先关阴影（`renderer.shadowMap.enabled = false`）或降 `bloom` 强度。

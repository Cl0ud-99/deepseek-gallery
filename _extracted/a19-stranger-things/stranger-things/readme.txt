《怪奇物语》霍金斯 / 颠倒世界 · 双世界镜像微缩场景
=====================================================

文件
----
stranger-things-hawkins-diorama.html   主文件（单文件，约 733 KB）

打开方式
--------
双击这个 .html 文件即可，推荐用 Chrome / Edge / Safari 最新版。
不需要联网，不需要安装任何东西，three.js 已完整内联在文件里。
（第一次打开会有 1~2 秒贴图生成时间，属正常现象。）

操作
----
· 鼠标左键拖拽：旋转视角
· 滚轮 / 触控板双指：缩放
· 触屏：单指旋转，双指缩放
· 静止约 7 秒后镜头自动缓慢环绕，鼠标一碰即停
· 画面没有任何 UI，纯场景

性能提示
--------
桌面独显 / 核显可满帧运行。若笔记本较老出现卡顿：
· 把浏览器窗口缩小一些（分辨率越低越流畅）
· 关闭其他占用 GPU 的标签页
· 移动端建议横屏观看，效果更好

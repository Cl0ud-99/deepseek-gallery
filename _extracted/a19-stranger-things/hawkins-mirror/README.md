# HAWKINS / THE UPSIDE DOWN — 上下镜像微缩沙盘

一个用 three.js **纯代码程序化建模**的《怪奇物语》双世界沙盘（未使用任何 DCC 软件）。
底座是 13×13 的正方形双层夹心板：现实世界的霍金斯街角建在板面上方，颠倒世界以 180° 倒悬镜像挂在板面下方。

---

## 一、直接看

双击 **`hawkins-mirror.html`** 即可（单文件，three.js 已内联，离线可用，无需服务器）。

| 操作 | 效果 |
| --- | --- |
| 左键拖拽 | 环绕旋转 |
| 滚轮 / 双指捏合 | 推拉缩放（9 ~ 52） |
| 右键拖拽 / Shift+拖拽 | 平移视点 |
| 静置 5 秒 | 自动缓慢环绕（转动台） |

> **看两层的诀窍**：底座是两层**共用的一块实心地面**，俯角一高，底板就会像屋檐一样把下半世界整个挡住。
> 默认机位压在仰角 ≈9°，此时上下同时可见；想看颠倒世界的**室内**（它的天花板朝下），把镜头绕到板面**下方**去。

## 二、改代码

源码是普通的 `<script>` 顺序加载，没有构建工具、没有 npm 依赖。

```
hawkins-mirror/
├── hawkins-mirror.html   ← 打包后的单文件成品（可分发）
├── index.html            ← 开发入口：直接双击，改完刷新即可
├── build.js              ← 把 src/*.js 内联进单文件：node build.js
├── src/
│   ├── core.js           ← 色彩管理 / 随机数 / 画布纹理库 / 卡通材质 / 描边 / 几何辅助
│   ├── world.js          ← 底座、地面街道、建筑外壳、街道道具、交界裂缝
│   ├── interior.js       ← 两层室内陈设、霓虹招牌、腐化处理（藤蔓/菌毯/裂缝）
│   ├── fx.js             ← 降雨 / 涟漪 / 玻璃雨痕 / 孢子 / 雷电 / 夺心魔 / 湿地反光
│   └── main.js           ← 场景装配、灯光、轨道相机、主循环
└── vendor/three.min.js   ← three.js r149 (UMD)
```

开发流程：改 `src/*.js` → 双击 `index.html` 刷新看效果 → 满意后 `node build.js` 重新生成单文件。

## 三、想调什么，改哪里

### 1. 配色
`src/core.js` 里的 `ST.pal`，两套表一一对应：
- `real` = 现实世界（暖霓虹、湿沥青、薄荷绿外墙、奶油色饰条）
- `up`   = 颠倒世界（暗青、锈褐、熄灭的霓虹）

> 注意：本项目已开启 `THREE.ColorManagement.legacyMode = false`（r149 的开关名，不是 `.enabled`）。
> 十六进制色会按 sRGB 解释再转线性。**如果关掉它，所有深色会被 sRGB 输出提亮成粉彩色**，整座城会变成塑料玩具。

### 2. 版式与体量
`src/world.js` 顶部的 `ST.GEO`：

```js
HALF: 6.6,     // 底座半宽（总 13.2）
ROAD: 2.8,     // 车行道起始
WALK: 2.0,     // 人行道内缘
ARC: { x0:-1.7, x1:2.0, z0:-4.0, z1:2.0, h:3.3 },  // 皇宫街机厅
HSE: { x0:-5.5, x1:-1.8, z0:-4.0, z1:0.9, h:2.75 },// 拜尔斯老屋
```

`ST.BASE_H`（默认 0.56）是夹心底座总厚度，改它要同步改 `main.js` 里 `upw.position.y`（已用变量引用，自动跟随）。

### 3. 灯光
`src/main.js` 的「灯光」段。关键几盏：
- `moon` —— 冷蓝主光，唯一投影源
- `hemiDown` —— **反向半球光**（ground 色照亮朝下的面），这是让倒悬世界能被看见的关键
- `below / below2 / below3 / below4` —— 从深渊往上打的四盏冷/红光
- `spill` —— 街机厅暖光外溢
- 室内点光在 `interior.js` 里，都带 `if (!up)` 判断

### 4. 动效强度
`src/fx.js`：雨滴数量 `N = 6000`、下落速度 `aSpeed`、涟漪扩张 `(0.09 + t*0.62)`、孢子 `span`、雷电间隔 `ST.rr(2.4, 5.5)` 秒。

### 5. 镜像的实现方式（重要）
`ST.buildWorld(theme)` 是**同一份建模代码跑两遍**（`'real'` / `'up'`），下层组只做 `scale.y = -1` 挂到板下：

```js
var upw = ST.buildWorld('up');
upw.scale.y = -1;
upw.position.y = -ST.BASE_H;
```

负行列式会由 three 自动翻转正面朝向，不用特殊处理。
因为共用一份代码 + 固定随机种子（`ST.setSeed(1983)`），上下连随机细节都严格一一对应。

## 四、调试参数（URL 查询串）

成品和开发页都支持，用于冻结画面、固定机位、强制闪电：

```
?shot=1          冻结时间（截图用）
&t=4             设定动画时间（秒）
&az=0.55         方位角（弧度）
&el=0.155        仰角（弧度，负值可绕到底下看倒悬世界）
&dist=20.2       机位距离
&tx=&ty=&tz=     视点中心
&bolt=1          强制触发一次雷电（能看到深渊里的夺心魔剪影）
```

例：`hawkins-mirror.html?el=-0.3&dist=14&ty=-2.4&az=0.9` —— 钻到板子下面看腐化室内。

## 五、已知取舍

1. **上下不能同时看到内壁**：这是镜像结构决定的。上层室内朝上，下层室内朝下。
2. **雨不会落进室内**：雨滴着色器里对两个建筑足迹矩形做了 `gl_PointSize = 0` 剔除。
3. **描边是反向壳**：法线外扩的 BackSide 材质，细长物件的外扩厚度需要单独给（`ST.bx` 的 `ol` 参数）。
4. **性能**：约 900 个网格 + 描边各一份 = 约 1800 draw call，独立显卡上流畅；软件渲染（SwiftShader）会很慢，属正常。

# 极光星海 · 倒置沙漏天文台（三维箱庭）

一个纯前端、可自由拖拽 / 旋转 / 缩放的三维微缩场景。全部几何体、贴图、着色器均由代码程序化生成，没有任何外部模型或图片资源。

---

## 一、只想看效果（换电脑、无网络也能跑）

直接双击根目录的 **`index.html`**。

这是**离线自包含版**：Three.js 与全部代码已经打包进同一个 HTML 文件里，不依赖网络、不依赖本地服务器，Chrome / Edge / Firefox / Safari 均可直接打开。

> 打开后镜头会极缓慢自转；鼠标左键拖拽旋转、滚轮缩放、右键拖拽平移。第一次操作后自转自动停止。

---

## 二、想继续修改

源码在 **`src/`** 目录：

```
src/
  index.html      页面外壳（背景色、全屏样式、importmap）
  main.js         全部场景代码（约 1900 行，分 10 个小节，带中文注释）
  vendor/
    three.module.js        three.js r160
    addons/                用到的官方扩展（OrbitControls / EffectComposer /
                           UnrealBloomPass / ShaderPass / OutputPass / BufferGeometryUtils 等）
```

**因为浏览器不允许 `file://` 下加载 ES Module，开发版必须通过本地服务器打开：**

- Windows：双击 `start-windows.bat`
- macOS / Linux：`./start-mac-linux.sh`（或任意静态服务器）
- 或者手动：在本目录执行 `python -m http.server 8080`，然后访问
  `http://localhost:8080/src/`

改完 `src/main.js` 刷新页面即可看到效果，无需构建。

### 改完后重新生成离线单文件版

```bash
npm install          # 只装 esbuild
npm run build        # 生成新的根目录 index.html
```

## 三、`main.js` 代码结构（按小节查找即可）

| 小节 | 内容 |
| --- | --- |
| 0 | 渲染器 / 相机 / 轨道控制器（初始机位、缩放范围、自转速度） |
| 1 | 通用工具（Canvas 贴图、三渲二渐变贴图、轮廓线外壳） |
| 2 | 材质库 `M`（黄铜 / 白玉 / 星尘等）与玻璃着色器 `makeGlass()` |
| 3 | 灯光与环境反射贴图 |
| 4 | 星空穹顶 + 星点 |
| 5 | 正方形双层底座（陨石层侧面、镜面浅水、白玉星盘、石阶、栏杆） |
| 6 | 倒置沙漏水晶天文台（玻璃壳、黄铜肋、星环、内部陈设） |
| 7 | 星座连线玻璃捕星花房 |
| 8 | 外景道具（浑天仪星环、新月小舟、捕梦网路灯、花坛、路牌、石台、陨石） |
| 9 | 后期处理（泛光、暗角、色散） |
| 10 | 主循环与动画注册 `onFrame()` |

### 几个常用调参位置

- **初始视角**：`camera.position.set(...)` 与 `controls.target.set(...)`
- **整体亮度 / 色调**：`renderer.toneMappingExposure`
- **泛光强度**：`new UnrealBloomPass(..., strength, radius, threshold)`
- **配色**：材质库 `M` 与水面着色器里的 `uAuroraA / uAuroraB / uDeep`
- **动效**：所有动画都用 `onFrame((t, dt) => {...})` 注册，`t` 为秒，`dt` 为帧间隔

## 四、场景清单

- **底座**：正方形双层结构。上层是半透明镜面浅滩（极光倒影、星点、涟漪），下层是幽蓝陨石层，侧面用程序贴图绘出金色星轨齿轮；外圈白玉围边、白玉石阶与环形栏杆，中央是白玉星盘。
- **主体**：双层倒置沙漏形水晶天文台。一层有流淌金色星沙的巨型沙漏核心、摆满星云许愿瓶的弧形高架、悬浮塔罗牌与羽毛笔账本；二层有紫水晶望远镜、投射银河的全息星图桌、月亮躺椅与穹顶星灯。
- **花房**：星座连线造型的玻璃捕星花房，内育太阳花与玻璃星星风铃。
- **外景**：四道缓慢多轴自转的巨型黄铜浑天仪星环、新月小舟、捕梦网路灯、星尘花坛、星座路牌、羽毛笔石台、水面陨石碎片与流星结晶。

## 五、动效

星环多轴自转 · 星沙逆流上浮 · 水面极光流动与涟漪 · 金色星尘升腾 · 许愿瓶星云脉动 · 新月小舟浮动 · 全息银河与望远镜缓慢转动。

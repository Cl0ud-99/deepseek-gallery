綺羅弄 · 旗袍與留聲 — 便携说明
====================================

【只想看场景】
双击打开：
  standalone/qipao-diorama.html

这是完全离线的单文件，Three.js、代码和全部纹理都已内联；
不需要联网，也不需要安装 Node.js 或其他软件。
建议使用开启硬件加速的 Chrome / Edge。

【想继续修改】
项目源码位于 src/。
不需要 npm install，也没有外部依赖。
可选择：
  A. 安装 Node.js 后，在项目根目录运行：
       node tools/serve.mjs
     然后访问 http://127.0.0.1:5290/

  B. 直接双击 index.html（也是本地脚本，支持离线）。

修改完成后，重新生成单文件：
  node tools/bundle.mjs

更多说明见 README.md。

【操作】
  拖拽            环绕旋转
  滚轮 / 双指捏合  缩放
  右键拖拽 / Shift + 拖拽  平移
  静止 28 秒      缓慢自动环绕

场景无 UI、无人物。

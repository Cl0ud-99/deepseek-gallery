# 环境声实验（exp/ambience）

本地实验分支，**不推送、不部署**。目标：给 19 件程序化微缩场景加上按内容设计的环境声。

## 怎么跑

```bash
node _lab/serve.mjs          # → http://127.0.0.1:8090
#   /              实验室索引（19→21 件）
#   /audition      试听板
#   /expo          展览页（公网版的原型）
#   /s/A01 …       单个场景
```

打开首页 → 点任意一件 → 右下角点「🔈 点击开启环境声」。
URL 加 `?nosound=1` 可完全静音（截图、测量时用）。

## 声音从哪来

**没有任何音频文件。** 全部用 Web Audio 现场合成，和这批作品"零外部资源"的做法一致：

- **噪声床**：白 / 粉 / 棕噪声三种，各生成 4 秒循环缓冲，过了 biquad 滤波（雨、风、海、蒸汽）
- **低频 drone**：2~4 个轻微失谐的振荡器 → 低通，缓慢 LFO 起伏
- **随机事件**：19 种合成器（钟、滴水、雷、鸟、海鸥、金属撞击、蒸汽、无线电、时间卡顿……），
  按预设的间隔区间随机触发

链路末端挂了一个 DynamicsCompressor 防削波。

## 文件

| 文件 | 作用 |
|---|---|
| `ambience.js` | 引擎 + 19 个预设（唯一需要维护的源） |
| `inject.mjs` | 把引擎内联进 19 个场景入口，幂等；`--strip` 可全部移除 |
| `serve.mjs` | 本地预览服务器 + 实验室索引页 |

注入的是 `_extracted/` 下的**成品入口 HTML**，不改任何 `src/`。标记块：

```html
<!-- AMB:start --> … <!-- AMB:end -->
```

## 自检

`Ambience.renderOffline(id, 秒数)` 会用 OfflineAudioContext 把某个预设离线渲一遍并返回
`{rms, peak}`，用来批量确认"每个场景真的出声、且不削波"。19 个预设当前实测：

rms 0.038–0.164，peak ≤ 0.55，全部通过。

## 还没做

- 没有音量滑块（只有静音开关）
- 事件都是纯随机，没有和场景内的动画（电车经过、闪电、电梯）联动
- 没有做空间化（PannerNode），全部是双声道干声
- 只在桌面 Chrome 上测过
